# Format Data PSF

Gunakan fail CSV dengan lajur berikut:

`tarikh,modul,nilai,catatan`

Modul yang disokong:
- Baca dan Kongsi
- Kongsi Minda
- Statistik Pengunjung
- Pengguna ICT

Format tarikh: `YYYY-MM-DD`.

Fail ini ialah template dan **bukan data rasmi**. Data sebenar PSF perlu menggantikan sample-data.csv sebelum dashboard digunakan sebagai laporan rasmi.
