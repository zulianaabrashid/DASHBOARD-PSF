# Dashboard Interaktif Pusat Sumber dan Fotografi (PSF)

Dashboard interaktif untuk pemantauan statistik PSF mengikut **tarikh, bulan dan tahun**.

## Modul
- Baca dan Kongsi
- Kongsi Minda
- Statistik Pengunjung
- Pengguna ICT

## Paparan
- Ringkasan KPI
- Carta trend mengikut tempoh
- Penapis tarikh / bulan / tahun
- Perbandingan prestasi
- Reka bentuk corporate yang responsif

Repositori ini disediakan sebagai asas pembangunan aplikasi dashboard PSF yang boleh dikembangkan dengan sumber data sebenar.
